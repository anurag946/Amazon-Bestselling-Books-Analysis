# 📊 Amazon's 50 Bestselling Books Analysis (2009–2019)

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on Amazon’s Top 50 Bestselling Books dataset from 2009 to 2019.

The goal is to uncover trends in:
- Ratings
- Reviews
- Pricing
- Genre distribution
- Author frequency

## 🛠 Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Numpy

## 🔍 Key Insights
- Identified most frequently appearing authors
- Analyzed rating vs review correlation
- Explored price trends over years

## 📂 Dataset
Amazon Top 50 Bestselling Books (2009–2019)

## 🚀 How to Run
1. Clone the repository
2. Install required libraries
3. Run the Jupyter Notebook
